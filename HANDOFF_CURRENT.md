## 0.1.70.3 room contract

- Host is always **P1**.
- Online clients no longer choose their seat.
- Server auto-assigns the lowest free seat in join order: **P2 -> P3 -> P4**.
- Room settings are authoritative:
  - `cameraAllowed`
  - `voiceAllowed`
  - `cpuFill`
- Camera/voice are **policy only** in 0.1.70.3. No WebRTC media is active yet.
- Camera/mic remain OFF by default and will stay opt-in when media is implemented.
- Every human player, including Host, has a Ready state.
- Changing room settings resets human Ready states.
- If CPU Fill is ON, empty P2-P4 seats become CPU on Start.
- If CPU Fill is OFF, all four human seats must be occupied and Ready.
- Only Host can Start.
- Only Host can Kick P2-P4.
- Kicked client IDs are session-banned for that room.
- Client reconnect identity is stored in sessionStorage and protected by a reconnect token hash on the server.
- Gameplay WebSocket connections validate the assigned lobby seat + reconnect token.
- Logical WebSocket channels remain isolated:
  - `game`
  - `turn-order`
  - `demo-shell`
