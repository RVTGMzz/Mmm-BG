# MeMeMe 0.1.57 — Authoritative Special Locations

Status: **AUTOMATED CANDIDATE / MANUAL RUNTIME ACCEPTANCE REQUIRED**

0.1.57 keeps the 0.1.56.1 canonical camera/HUD presentation and adds authoritative gameplay for Jail, Hospital, Lottery, plus Mini Game eligibility while a player is being held.

## Locked rules

### Jail / Đồn

- Landing on `M12 / SPECIAL_JAIL_GATE` sends the player to the Jail holding node.
- On that player's next turn, the normal `roll` action becomes a release check.
- Release succeeds on **1 / 3 / 5**.
- Failure: remain in Jail and the turn ends.
- Success: traverse `JAIL -> J1 -> J2 -> J3 -> M13`.
- The release D6 is only the escape check.
- After a successful release, `lastRoll` is cleared and the same player returns to `PRE_ROLL_ACTION` in the **same turn**.
- The player must roll a **fresh movement D6** before normal board movement begins.

### Hospital / Bệnh viện

- Landing on `M34 / SPECIAL_HOSPITAL_GATE` sends the player to the Hospital holding node.
- Release succeeds only on **2 / 4 / 5**.
- Failure: remain in Hospital and the turn ends.
- Success: traverse `HOSPITAL -> H1 -> H2 -> H3 -> M35`.
- The recovery D6 is not reused for movement.
- A successful recovery returns the same player to `PRE_ROLL_ACTION` for a fresh movement D6 in the same turn.

### Lottery / Xổ số

- `M23 / SPECIAL_LOTTERY` rolls a separate authoritative D6.
- Reward = `D6 × 20 B$`.
- Possible rewards: `20 / 40 / 60 / 80 / 100 / 120 B$`.
- The payout roll is generated by deterministic replay/HOST RNG, not by presentation code.

### Mini Game eligibility

- Players currently held in Jail or Hospital are excluded from Mini Games.
- **2+ eligible:** play normally.
- **1 eligible:** that player becomes automatic rank #1.
- **0 eligible:** skip the Mini Game and pay nobody.
