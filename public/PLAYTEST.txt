MeMeMe MVP 0.1.45 — REMOTE ROLL FOR ORDER

QUICK START — WINDOWS
1) Giải nén file ZIP playtest.
2) DOUBLE-CLICK: START_PLAYTEST.bat
3) Trình duyệt sẽ tự mở http://127.0.0.1:4173/ (hoặc cổng gần đó nếu 4173 đang bận).
4) GIỮ cửa sổ terminal launcher mở trong lúc chơi. Nhấn Ctrl+C để dừng server khi chơi xong.

QUAN TRỌNG
- KHÔNG double-click index.html trực tiếp.
- Nếu thanh địa chỉ bắt đầu bằng file:///C:/... thì game có thể chỉ hiện màn hình trắng vì browser chặn ES module/local asset khi chạy bằng file://.
- START_PLAYTEST.bat dùng local server và KHÔNG cần cài Node/Python.

PLAY MODES
- 1 HUMAN + 3 CPU: khuyến nghị để test một mình.
- 2 HUMAN + 2 CPU: test với một người bạn.
- 4 HUMAN HOTSEAT: 4 người tự điều khiển.
- 4 CPU AUTOPLAY: để game tự chạy cả trận cho QA.
- HOST 2 TAB + JOIN 2 TAB: PoC local, hai tab phải cùng browser profile/origin.

0.1.45 FOCUS — REMOTE ROLL FOR ORDER
- JOIN không còn nhảy thẳng vào board; client vào cùng màn Roll For Order với host.
- Client chọn P2/P3/P4 và giữ đúng ghế đó trong ceremony.
- Khi tới lượt ghế remote, nút D6 chỉ sáng trên tab client sở hữu ghế.
- Client chỉ gửi thao tác bấm roll + prompt ID, KHÔNG gửi kết quả xúc xắc.
- HOST kiểm tra đúng ghế/prompt rồi mới sinh D6 và broadcast kết quả authoritative cho các tab.
- Unclaimed seats vẫn do HOST bấm.
- Nhóm hòa chỉ reroll trong nhóm; remote seat hòa sẽ lại tự bấm trên tab remote.
- HOST broadcast final playOrder và chỉ HOST được release mọi tab vào trận.
- Player names sync từ HOST Setup; face files vẫn không được gửi qua mạng.

TEST 2 TAB KHUYẾN NGHỊ
1) Tab A → HOST 2 TAB → giữ room code → Setup → ROLL FOR ORDER.
2) Tab B → JOIN 2 TAB → nhập room code → chọn P2/P3/P4.
3) Host phải nhận remote seat rồi mới bắt đầu ceremony.
4) Khi tới remote seat, bấm D6 trên tab B; cả hai tab phải hiện cùng kết quả.
5) Nếu hòa, chỉ nhóm hòa đổ lại.
6) Client chờ HOST bấm VÀO TRẬN rồi cả hai mới sang board.

AUTHORITY CHECK
- Spam click remote roll không được sinh thêm D6 cho cùng prompt.
- Remote P2 không được roll prompt của P1/P3/P4.
- Late join sau khi ceremony khóa ghế phải bị reject rõ ràng.
- Roll For Order pregame không tiêu thụ gameplay RNG state.
