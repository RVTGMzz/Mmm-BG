QUICK START
1) Serve this folder with a static HTTP server. Do not rely on file://.
2) Open index.html through localhost / your static host.
3) SOLO / HOTSEAT is the fastest test path.
4) HOST 2 TAB + JOIN 2 TAB works only in the same browser profile/origin for this PoC.

DEMO RULE
- 4 players
- 3 rounds = 12 turns
- highest B$ wins
- tied B$ = tied winner
- this is a temporary playtest rule, not the final MeMeMe win condition
